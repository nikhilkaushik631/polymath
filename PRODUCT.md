# Polymath

## Register
product

## Users and purpose
A single local macOS application for previewing PDFs, office documents and source files, writing documents and Markdown/plain text, working with spreadsheets, creating presentations, editing images, and playing local audio/video. The owner switches between these tasks throughout a day and uses coding agents to author files.

## Direction
One application, one window, one installer. Home is the workspace switcher; a compact global bar returns to it. Reader is a focused read-only PDF, office, image and source viewer; an Edit action opens the original in the right workspace. Writer is also the common editor for Markdown and plain text, with a native Save As format choice. PDF Tools is a separate workspace backed by the same PDF session. Workspace switches keep unsaved documents and undo histories. Native folder permissions, no account, no cloud integration, no update checks. Preserve the five engines, original licenses, document colors, and photo colors.

## Appearance
Neutral surfaces in light and dark modes, with restrained workspace accents: blue for Reader and PDF Tools, teal for Writer, green for Sheets, terracotta for Slides, and amber for Images. A distinct original Polymath application icon and six matching workspace symbols. Text and controls default to 125% scale; sidebars remain narrow.
