# Codex in Polymath

`AGENTS.md` is the shared repository instruction file that Codex reads. This file is the practical quick start for using the app; [the full agent guide](docs/USING_WITH_AGENTS.md) defines the local control protocol. Open this repository as the Codex project so its project-local `.codex/config.toml` can expose the `polymath` MCP bridge. Reload Codex after changing that configuration.

For document work, inspect the existing app state first with `polymath_inspect`. Use `polymath_open {path}` to open a read-only Reader tab, then use Edit for a deliberate editor handoff. Switch with `polymath_switch {workspace}`; valid workspaces are `home`, `reader`, `tools`, `writer`, `sheets`, `slides`, `images`, and `video`. Discover actual editor actions with `polymath_commands {workspace}` before calling `polymath_execute {workspace,command,params}`. Inspect the result with `polymath_document {workspace}`, save to the path the user chose, then reopen or render the saved file. [Workspace guides](docs/README.md) explain formats and UI behavior.

The bridge starts a separate agent-enabled Polymath instance on demand. Normal app windows do not start a control listener, and the bridge does not attach to or close a normal window with unsaved work. Keep the endpoint token private. A `polymath_screenshot` is useful for visual review; it does not prove the saved document is correct. Do not use a personal file as a published example without the user's request.

For app development, read [product direction](PRODUCT.md), [design rules](DESIGN.md), [architecture](docs/ARCHITECTURE.md), and the relevant sibling engine guide before editing. Keep all five sibling checkouts and their licenses. Use `CARGO_BUILD_JOBS=1` because Polymath and Reader share a Cargo target on this Mac. Validate the affected workspace, preserve open documents and undo histories, and do not replace a running installed app that may contain unsaved work. The local build and validation commands are in [README](README.md) and [validation](docs/VALIDATION.md).
