# Home and Settings

Home is the entry point for Reader, PDF Tools, Writer, Sheets, Slides and Images. The two featured surfaces lead to reading and PDF work; the four smaller cards lead to creation and editing. The shared top bar's **Home** action returns here while keeping editor sessions open. A dot by a workspace name means it has unsaved changes.

The interface uses color to identify the current workspace: blue for Reader and PDF Tools, teal for Writer, green for Sheets, terracotta for Slides and amber for Images. Selected controls and primary actions use the same color in light and dark themes. File pages, spreadsheet cells and photo canvases keep their own document colors.

Use **Open file** or ⌘O to let Polymath choose a workspace from the file type. Markdown and plain text open in [Reader](READER.md); use **Edit in Writer** when needed. Other editable formats open in their editor, and Reader can preview them first. **Continue working** shows the latest files above the workspace cards, within the first screen. The full searchable recent-file list remains below the cards. These are actual files opened through Polymath or directly inside Reader, Writer, Sheets, and Slides, including newly saved documents; Home also brings in existing editor histories on launch. Search and type filters appear once there is something to browse. The narrow Library rail shows Recent files and folders you explicitly added.

**Add folder** opens the macOS folder picker. Polymath lists supported files only inside folders you selected; it does not crawl other folders or follow symlinks. Remove a folder from the sidebar context menu or **Settings → Files & privacy** to stop listing it; removal does not delete files. Refresh updates the current listing. If macOS access has expired, choose the folder again in the system picker.

The gear opens one Settings window. **Appearance** selects Light or Dark and can reduce Home motion. **Voice** holds dictation language and installed macOS narration voice; see [Voice](VOICE.md). **Files & privacy** manages selected folders and explains local file handling. The sun/moon button in the shared bar switches themes directly. These settings live in Polymath's Application Support directory on this Mac.

The current installed copy may differ from the source build. To install a new local DMG, save work and quit the old Polymath instance before dragging the new app to Applications. The application is ad-hoc signed and has no account, telemetry or cloud sync in normal use.
