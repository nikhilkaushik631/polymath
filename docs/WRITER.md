# Writer

Writer edits Word documents, Markdown (`.md`) and plain text (`.txt`) in the same document workspace. Home's **Open file** routes these formats here. Reader can show them first without editing; **Edit in Writer** then opens the original. Writer keeps its document while you visit another workspace, and Polymath checks its unsaved state before quitting.

Use Writer's **Save** for an existing document. The **Save As** menu beside the toolbar's Save icon offers **Word document (.docx)** and **PDF copy (.pdf)** while keeping the document in view. Both choices open a native dialog to choose a location. Word becomes the editable saved document. PDF creates a separate copy, leaving the open document and its unsaved state intact. Clicking **File** opens a compact menu over the document with the same Save As choices. **Writer Home** in that menu opens the full Writer start page when you want templates or Writer's own recent list. **More formats** and F12 open the full Save As page, which includes Markdown and plain text; the native dialog lets you choose `.md` or `.txt`. Converting among formats may not preserve every layout feature, so reopen the saved file and inspect it before relying on it.

The toolbar microphone can dictate into the focused editable text field using the local model; see [Voice](VOICE.md). Coding agents should discover Writer's actual command names with `polymath_commands {workspace:"writer"}` and verify saved output. The deeper [Writer control protocol](../../writer/docs/control-protocol.md) documents its engine and UI commands.
